# Obsidian / Markmap-style markdown

## Features
- [x] Task that is done
- [ ] Task still open
- A plain bullet
  - Nested child bullet
- ==Highlighted== and [[Some Page|an alias]] and #atag

## Notes
> A blockquote becomes a note on the previous node.
> [!warning] A callout keeps only its text.
